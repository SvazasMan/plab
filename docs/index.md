
# Probability Laboratory

Probability Laboratory (`plab`) is a Python project for
exploring Probability Theory, Statistics, and Machine Learning.

## Objectives

- Implement mathematical algorithms in Python.
- Explain the underlying mathematical theory.
- Test correctness and numerical behavior.
- Compare implementations with established libraries.
- Provide reproducible educational examples.

## Project Areas

### Probability Theory
Probability spaces, distributions, expectation, and simulation.

### Statistics
Descriptive statistics, estimation, and hypothesis testing.

### Machine Learning
Optimization, regression, and learning algorithms.
